# 当前进展记录

## 已完成

依据本目录两份用户提供的原始文档，验证了整数 Block 矩形占用、边界 Block Port 配对、水平镜像、部分 Port 使用及占位封口、有向 Route 实际图和奖励返回关系。

初版采用固定三条水平路线带，无法充分表现尺寸和接口偏移带来的二维变化。当前保存的第二版改用自由二维前沿生长，保留了宽扁、细高、不同 Port 高度和同侧多 Port 的组合。初版没有作为当前基线继续沿用。

当前生成器先准备固定模板库，按 Port 的朝向和地貌建立检索索引；用精确 Port 坐标推出原点并检查不重叠，再根据额外连接、包围面积增长、模板重复和随机扰动选择候选。局部闭环使用有界 Beam Search，最大深度 3、每层保留 18 个候选状态。

单图 Seed 271028 有 49 实例、37 已用模板、18 尺寸、61 接缝、6 奖励、20 镜像。122 个已用 Port 端点中 116 个不在 Module 边中点，35 处左右接缝中 26 处使矩形上下错开。

## 固定 Seed 批次

固定 52 个测试模板、能力集合与生成参数，连续测试 271028–271047，无重试或替换。源文件快照和哈希、完整候选数据均保留。

| 项目 | 结果 |
|---|---|
| 首次通过完整静态检查 | 16/20，80%（仅此样本批次） |
| 拒绝 | 4/20 |
| 合格图实例数 | 43–49 |
| 合格图接缝数 | 59–67 |
| 合格图尺寸种类 | 17–20 |
| 合格图奖励 | 每图 6 处，均可达且有合法后续去向 |
| 合格图实例可达 | 全部实例可从 Start 到达 |
| 可选 AIR 回路 | 7/16 合格图接入 |
| 左右接缝上下错层比例 | 合格图平均约 67.8% |
| 未用 Port 比例 | 合格图平均约 31.2% |
| Python 生成耗时 | 本容器合格样本约 1.29–1.71 s，平均 1.43 s |

耗时不含独立检查和文件输出，不是 Godot 或目标设备的性能基准。几何邻接图的环数忽略内部 Route 和方向，不能解释成同等数量的实际双向探索环。每图查出的三个通路示例是图论路径，不宣称已经形成三种不同的玩家体验路线。

271031、271043、271044 是奖励后无通往 Boss 的合法去向；271039 是一处奖励不可达。所有四张在奖励检查之前都通过了 Start→Boss 检查，最终被拒绝，没有当作有效地图交付。

失败邻接模块启用了 L/U/D，实际 Route 只有 L↔U、L↔D，缺少 U↔D；L 的外部方向又受到单向结构约束。需要在放置奖励前检查完整初始有向关系，而非仅检查几何或把同一 Module 的 Port 当作两两互通。

## Module 库建议

当前 52 模板是为探索几何机制准备的夹具。另提供 60 个离线内容制作任务，包含尺寸、Port 所在边界 Block、权限和目标 Route，尚未用于上述 Seed 测试。

建议保留同高、小错层、大错层、转角和纵向连接的覆盖，增加明确的两口回程连接。奖励任务配额为折返 5、单向环回 2、异位汇入 2。每个新基础模板必须具有独立内容；镜像或 Port 子集不单独计数。
