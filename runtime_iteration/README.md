# 0.4.2 速度与多样性候选

基于 main `b15c32e045347e0fcf282d541ea3eaa4661f0835` 和原 0.4.1 独立包。实现版本为 `mapgen/gdscript-candidate-0.4.2`，继续 `stable-v3-reward-space`、模块1.1.0与runtime-map/v2。旧包/默认配置/预期不改；本轮没有修改主游戏和 map-edit，不把开发入口接入误称正式出发。

本轮将计算改动与布局选择分开：

- 计算优化：保持原默认完整结果，采用精确整数坐标 pair key，避免权限判断的临时数组；为不可变实际图复用反向可达集合，等价回答“能否到 Boss”。原 Route 及其方向没有改变，反向图只用于内部查询；随机调用、候选/回退/终端计数不变。
- 可选多样性配置 `profiles/stable-v3-varied-v1.json`：只改现有 `repeat_module:5→8`，其他评分和所有约束/预算保持原值。配置文件名和包 manifest 记录独立 profile 身份，原默认 `profiles/stable-v3-reward-space.json` 保留。未新增隐藏权重、随机源、目标、检查例外或第二套生成协议。

布局差异来自显式评分配置，配置本来就参与指纹，因此不为调现有评分而改算法名或升级 Schema。不同配置的地图、RNG状态和搜索计数允许不同，必须分别对照；纯计算优化的旧结果一致性不能代替新配置验收。选用哪个配置由宿主在创建请求 job 前明确决定，不根据运行失败自动切换。

## 调用与集成

安装包内完整 `addons/mapgen/`（仍19个运行文件），按新 manifest 的 SHA 显式换锁；模块 ZIP 继续明确输入并验证1.1.0原SHA。继续 `PreloadJob.create(path,sha)` → advance/progress/cancel/result → 已通过的 library → `GenerationJob.create(request,library,config)`。同一 verified library 可复用，所有求解与可达缓存属于独立 job，完成结果是快照。算法不认识 LevelPlan、SceneTree、bindings、source_record 或 run/stage/actor token；宿主仍主线程装配和守卫生命周期。

新实现身份参与指纹。默认配置的 layout/content/RNG/计数不变，输入指纹/map_id/实现字段会改变；多样性配置还会产生真正的布局、内容选择和计数差异。不要沿用旧恢复/装载身份，不把新包的 source commit 或产物提交改写成未来 main merge。

先按原默认配置核对接入，再明确选择多样性 profile，并把该配置的字节SHA纳入宿主锁。已有 Job/Provider/安装器对实现及包版本的准入需同步 0.4.2；调度循环与数据转换合同无需重写。包内样例是校验向量，生成器从不查询地图样例。

默认单位仍是16检查点，`advance(1)`不是毫秒承诺。保持原90秒/500000候选及检查间隔、32生长/6目标奖励/3主路、最大长短边比3和封口32像素。默认与多样性两种配置均遵守同一组检查。宿主让帧计入原墙钟限制，只有PASS可用；搜索失败、预算耗尽或取消仍无 map/content_store。

## 证据和局限

[REPORT.md](REPORT.md) 给出本次真实 Godot 4.7.2 native/Web 的旧新时间、取消延迟和配置区别；地图对照同时给出模块身份、镜像折叠后的平台/Port-Route类型、邻接模式及归一化占用相似度。模块身份数增加不单独当作布局或玩法多样性证明。

[115个源模块的使用频率](module_usage/README.md)补充同批60 seed的完整CSV/可搜索表格、零使用和局部Route/封口组合诊断；区分四能力回归频率与主游戏两能力请求的可选性，不改变已有算法或包。

所有成功、失败和未采用试验保留。大放置/前缀缓存收益很小、几何计划缓存更慢，均未加入运行组件；对应 patch 可在原0.4.1独立项目重建，不是另外的交付包。原 40 seed 全部保留，另测失败、预算、取消、推进批次及共享库隔离。完整有效性继续使用已有独立源内容/有向图/封口/所有奖励检查。

仍为 candidate：静态生成不等于整图动作/出生/奖励/跨缝认证；未证明玩家主观重复感已经解决。主游戏普通出发仍在其旧 Provider 后，本轮仅为后续正式接入准备。Web与原生分开报告，不代签主游戏整段、设备或硬帧保证，不升级模块1.1.1，不添加地图级危险或随机布怪，不部署或自动合并。
