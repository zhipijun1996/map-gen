## 性能与已知边界

实测平台 Linux / AMD EPYC 9V74 / Godot 4.7.2-stable official / 60Hz。录屏是 Xvfb + Mesa llvmpipe；Dummy 音频，无听感或实体低端设备结论。最终准确分阶段数据在 summary.json；预加载等待与主线程装配分别计时，不混为布局求解耗时。

后台只加载实际场景与区域显式 prewarm_resources。原“预载宿主全部脚本”的开发尝试导致退出错误/卡住，已撤回，原日志保留。宿主锁里包含工具和测试脚本，不能全盘执行式预加载。

模块一次原生 _ready/bind_player 不能被打断，单模块步骤可能超过配置软预算。8ms 不是硬上限；首次启动还需包哈希和资源准备。要稳定达到更低长尾，需烘焙/可分步的模块工厂。多个连续地图的节点和信号清理通过，但日志仍保留原生 GDScript/ObjectDB 退出资源警告，未宣称全进程无资源泄漏。

本轮未交付 Web 试玩页，未验证 Godot 导出重映射后原始文件哈希的保留链；离线 Godot 项目是可运行交付入口。最新主游戏 5f55716 的安装适配保留上游 API 兼容范围，尚未开展该宿主上的路线复验，因此不借用原生宿主的物理备用图。
