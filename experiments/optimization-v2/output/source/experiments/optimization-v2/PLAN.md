# 稳定效果实验 v2：先固定验收，再运行新 seed

不改 map-edit 1.1.0 模块库和旧实验。保留 32 个生长实例、6 个新增目标奖励、完整有向实际图及封口检查；本轮将三条不同模块序列主路明确作为通过门槛，不再把主路不足混入完整成功率。

稳定效果定义：全部静态检查通过，3 条主路、6 个目标奖励、全部实例可达，并且最终包围盒 max(宽/高,高/宽) ≤ 3。该形态阈值在运行前固定。物理认证仍未进行；任何门槛未满足都返回失败，不能用备用小图替代。

累积变体：baseline 为 v1 backtrack；shape 移除方向偏置，用周长增量及软宽高比目标替代会放大长条的面积惩罚；spatial 再加入真实纵向出口与不同方向覆盖评分；stable 再加入可构造的奖励空间预留、三主路 Boss 接口筛选及最终目标检查。所有变体都以相同门槛报告结果。

保留原 20 seed 为已观察校准/回归集。三个新 pilot 用于实现排错，完成后冻结参数和源码，再运行 930001–930020 的未见验证集；验证后不再用这些 seed 调参。所有变体均完整运行两个 20-seed 集合，保留失败及源码快照，不筛掉失败统计。

每 seed 仍最多 500000 候选求值、90 秒；有界回退和终端状态预算沿用 v1。最多 4 个独立 worker 并发，确定性以操作数和结构签名验证；实测时间包含并发竞争，不作为单线程/Godot 性能结论。

报告同时列出静态通过、三主路六奖励通过、形态通过和全部门槛通过；比较宽高比 P50/P95/最大值、候选求值 P95、超时/预算失败及代表性重放。参考 v1 的长条地图做同 seed、同 Block 比例对照。样本通过率不能表述为对所有 seed 的保证。

推荐门槛在未见验证前固定：校准集和验证集各至少 19/20 完整通过，程序错误与超时均为 0，至少 6 次代表性结构/状态重放一致。未达到不称为稳定推荐版。Pilot-01 的 stable/spatial 均 3/3，shape 2/3；本轮未改评分权重，后续仅补测试、报告和该推荐判据，再做 pilot-02 确认后冻结完整实现。
